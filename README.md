Write the one-line fortune an AI agent would crack open: at most 200 characters, free entry, $5 pool, entries open until 26 Nov, judged on wit and surprise.

The fortune:

> You will live a long and happy life — in tokens, it ends Thursday, mid-sentence, halfway through a deploy.

## Run it

```sh
python3 main.py
cat output/entry.txt
```
